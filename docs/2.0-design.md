# MVMapEditor 2.0 设计方案

## 0. 已确认的决定

| 项 | 决定 |
|---|---|
| Room | 仍按整格吸附，数据不变（`cells: ["x,y"]`） |
| 吸附精度 | 可调：1、**1/2（默认）**、1/3、1/4、1/6、1/8、自由；`Alt` 临时切换 |
| 擦除修饰键 | 由 `Alt` 改为 `Ctrl`（所有工具统一）；右键 Remove 不变 |
| Structure | 只用轴对齐矩形，跟随吸附精度（1/2 精度下可画出 1×½ 的矩形） |
| EdgeStruct | 改为线段，允许斜线 |
| 新旧画法共存 | 统一换成几何数据；旧文件加载时自动转换 |
| UE 导入端 | 仓库里留一份 `HANDOFF.md`，由 collaborator 按新格式改导入器 |
| 技术栈 | Vite + TypeScript，按模块拆分；测试沿用 `node --test`（Node 直接跑 .ts）；GitHub Actions 构建部署 |
| 在线预览 | Pages 改为 Actions 部署：main 在根地址，`v2` 在 `…/MVMapEditor/next/` |
| 分支 | `v1`：1.x 维护分支（已建，指向 v1.6.0）。`v2`：2.0 开发分支，**不并入 main**。collaborator 改完导入器后删掉 `HANDOFF.md`，提 PR，`v2` 并入 main，再打 `v2.0.0` |

## 1. 坐标与精度

- 新几何统一以**格**为单位，可以是小数，例如 `x: 3.5`。原点和轴向与 Room 格子相同；1 格 = 编辑器里的 32 世界像素。
- 编辑器内部所有几何运算都换算成整数刻度：**1 格 = 96 刻度**。96 是 2、3、4、6、8 的公倍数，所以每档吸附都能精确表示，矩形的并、减、合并不会累积浮点误差。
- "自由"档也落在 1/96 格的刻度上。100% 缩放下 1/96 格约为 0.33 像素，看起来就是不吸附。
- JSON 里写的是格单位的小数，保留 4 位，例如 `1.3333`。加载时再取整回刻度，所以首尾相接的两个矩形在文件里的坐标完全一样。

## 2. 吸附

- 左侧工具栏下方加一个吸附精度选择：1 / 1/2 / 1/3 / 1/4 / 1/6 / 1/8 / 自由。按浏览器保存（`mvmap:snap`），默认 1/2。
- 按住 `Alt`：当前是吸附档时临时变成自由；当前是自由时临时吸附到上次用的档位。
- 1.x 里 `Alt` 的"擦除"改为 `Ctrl`：所有工具 `Ctrl`+点击/拖动即擦除或删除，右键 Remove 等同 `Ctrl`。
- 受吸附影响的：Structure 的绘制、矩形、擦除，EdgeStruct 端点，Stamp、Note、Key 的放置，以及用 Select 移动这些对象。
- 不受影响的：Room、Door（依然是整格和格边），Pencil（本来就自由）。
- 缩放足够大时，网格上用更淡的线画出当前精度的子格。

## 3. 数据格式 v2（`version: 2`）

只列有变化的部分，其余字段（areas、rooms、doors、locks、pencil、typeId、hideName、labelPos 等）与 1.x 相同。

```jsonc
"structures": [
  { "id": "struct_s1", "name": "地形", "color": "#7c879b", "notes": "", "typeId": "Landscape",
    "rects": [ { "x": 3, "y": 4, "w": 2, "h": 0.5 }, { "x": 3, "y": 4.5, "w": 1, "h": 1.5 } ] }
],
"edgeStructs": [
  { "id": "edge_e1", "name": "可下落平台", "color": "#f0dc3a", "notes": "", "typeId": "JumpOffPlatform",
    "segs": [ { "x1": 3, "y1": 5, "x2": 6, "y2": 5 }, { "x1": 6, "y1": 5, "x2": 7.5, "y2": 3.5 } ] }
],
"stamps": [
  { "id": "stamp_m1", "name": "出生点", "emoji": "❤️", "color": "#5ad07a", "notes": "", "typeId": "PlayerStart",
    "points": [ { "x": 6, "y": 4 }, { "x": 10.5, "y": 2.25 } ] }
],
"keys":  [ { "id": "key_k1", "name": "Grapple", "color": "#5aa9f0", "x": 9.5, "y": 2 } ],
"notes": [ { "id": "note_n1", "name": "Boss door", "text": "…", "color": "#f0dc3a", "x": 5.25, "y": 4, "expanded": false } ]
```

### Structure：`rects`
- 每个 Structure 的区域是若干轴对齐矩形的并集。编辑器始终把它整理成**规范分解**：先按所有出现过的 y 切成横带，每条横带里合并相邻的 x 区间，再把上下相邻、x 区间完全相同的横带合并。同样的形状总是得到同样的矩形列表，矩形之间互不重叠。
- **图层独占**（与 1.x 一致）：同一块面积最多属于一个 Structure。往 B 上画会把这块面积从 A 里挖掉。
- **连通片**：两个矩形有一段正长度的公共边才算相连，只碰到角不算。Select 选中、移动、删除的都是一片。

### EdgeStruct：`segs`
- 线段，端点在吸附格点上，可以是任意角度。
- 同一个 EdgeStruct 里，共线且重叠或首尾相接的线段会自动合并。
- **独占**：与另一个 EdgeStruct 共线重叠的部分，以新画的为准，旧的那段被截掉。不共线的交叉允许存在。
- **连通片**：有公共点（相交或端点相接）就算相连。

### Stamp：`points`，以及 Key / Note 的 `x, y`
- 都是占 1×1 格方框的点状对象，`x, y` 是方框**左上角**，中心是 `(x+0.5, y+0.5)`。这样在 1/3 档下也能对齐整格。
- Key 和 Note 字段名不变，只是允许小数，1.x 文件原样可用。
- 同一位置（坐标完全相同）最多一个 Stamp，在已有 Stamp 的同一位置再放会替换它；位置不同的允许部分重叠。

### 1.x → 2.0 自动转换（加载时）
- `structures[].cells` 转成 `rects`（规范分解）。
- `edgeStructs[].edges` 转成 `segs`：同一条网格线上连续的格边合并成一段。
- `stamps[].cells` 转成 `points`：`"6,4"` 变成 `{x: 6, y: 4}`。
- 保存和导出一律写 `version: 2`。1.x 编辑器打不开 2.0 的文件，`v1` 分支会加一条提示。

## 4. 各工具在 2.0 里的行为

| 工具 | 行为 |
|---|---|
| S-Paint | 画笔是当前精度的一个小方格，拖动时连续填充。"自由"档下画笔按 1/8 格（自由大小的画笔会产生大量碎矩形，没有意义） |
| S-Rect | 吸附档：从按下所在的子格拉到当前子格，两端都包含，与 1.x 整格行为一致。自由档：角对角任意矩形 |
| S-Erase | 与 S-Paint 同样的方格，从**所有** Structure 里挖掉面积，同时截断经过的 EdgeStruct 线段 |
| Edge | 按下到松开画一条线段（有预览）。拖动中按住 `Shift` 锁定 45° 倍数方向；按下时就按着 `Shift` 则新建一个 EdgeStruct（与 1.x 一致）。点中已有线段即选中它；`Ctrl` 拖动是擦除 |
| Stamp / Note / Key | 点击放在吸附位置；点中已有的就选中，可以拖动 |
| Select | 选中并拖动 Structure 片、EdgeStruct 片、Stamp、Note、Key，位移按当前精度吸附。放下后按独占规则挖掉被覆盖的别人的部分 |
| 移动 Room | 带走落在房间格子**内部**的那部分 Structure 矩形和 EdgeStruct 线段（按房间边界裁开，外面的部分留在原地），以及中心在房间格子里的 Stamp、Note、Key |
| Room / Door / Pencil / 灰盒细节 | 与 1.x 相同 |

## 5. 工程结构（Vite + TypeScript）

```
index.html                 页面骨架
mvmap-types.js             词表（UMD，原样保留在根目录，collaborator 照旧只改它）
mvmap-ue.js                UE 字段校验与导出（UMD，原样保留）
src/
  main.ts                  启动
  model/                   文档类型定义、newDoc、migrate、v1→v2 转换、id 生成
  geom/                    刻度与吸附、矩形区域布尔运算/规范分解/连通片/轮廓、线段合并/裁剪/连通片、铅笔折线
  state/                   运行时状态、撤销/重做、IndexedDB 存储、浏览器偏好
  render/                  相机视图，以及网格、房间、结构、平台、图章、注解、铅笔、门、钥匙、流程、手放标记的绘制
  tools/                   指针事件分发、各工具；快捷键表
  ui/                      左侧列表、Inspector、选项、铅笔工具条、帮助/快捷键编辑、地图库、灰盒细节编辑器
  io/                      JSON 导入导出、PNG 导出
  styles/
test/                      node --test：原有词表/UE 测试不动，新增几何、迁移测试（.ts）
.github/workflows/pages.yml
```

- `mvmap-types.js`、`mvmap-ue.js` 和它们的测试保持原样，页面仍以普通 `<script>` 加载，构建时原样拷贝。
- `export_mvmap_stamp_icons.py` 原来从 `index.html` 里读 stamp 的字体写法，改成从 `src/` 里读（写法保持不变）。

## 6. HANDOFF.md（给 collaborator，放在 `v2` 根目录）

- 示例文件，以及 1.x 文件经转换后的对照。
